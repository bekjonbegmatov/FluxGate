# Fluxgate — панель управления HAProxy

Панель для маршрутизации по TLS SNI, учёта трафика серверов, квот и общих ограничений скорости. Поддерживает HTTP/1.1 и WebSocket.

## Запуск на этом VPS (systemd)

Запустите `sudo bash deploy/install-native.sh`. Скрипт собирает Go и веб-интерфейс, создаёт две службы `fluxgate-panel` и `fluxgate-haproxy` и сохраняет случайные секреты в `/etc/fluxgate/fluxgate.env`. Данные находятся в `/var/lib/fluxgate`.

Панель слушает **только** `http://127.0.0.1:9389/admin/` без HTTPS. Для доступа со своего компьютера создайте туннель `ssh -L 9389:127.0.0.1:9389 user@server` и откройте тот же адрес в браузере. Токен для входа смотрите командой `sudo sed -n 's/^PANEL_TOKEN=//p' /etc/fluxgate/fluxgate.env`.

Основной домен этого развёртывания — `cubeland.top`. При необходимости измените `PANEL_TIMEZONE=UTC` в `/etc/fluxgate/fluxgate.env`, затем выполните `sudo systemctl restart fluxgate-panel`. Направьте основной домен и SNI-имена серверов на VPS. Для `*.api.example.com` нужна wildcard-запись DNS.

## Запуск через Docker Compose

Скопируйте `.env.example` в `.env`, задайте домен и два разных длинных секрета, затем выполните `docker compose up -d --build`. Порт 9389 публикуется только на `127.0.0.1` хоста; панель также доступна по HTTP через SSH-туннель.

Публичный HAProxy слушает 443 с самоподписанными сертификатами. Клиенту понадобится доверять им или принять предупреждение. Для неизвестного SNI используется сертификат основного домена, поэтому браузер обычно покажет ошибку имени до fallback-страницы.

## Как работает трафик

HAProxy читает SNI из TLS ClientHello на 443 и выбирает маршрут. Локальный сервис Go считает байты TLS-потока и ограничивает общую скорость для всех соединений сервера. Затем поток возвращается в HAProxy на внутренний порт 8443: там завершается TLS, а HTTP или WebSocket направляются к конечному HTTP/HTTPS-серверу. Основной домен всегда показывает редактируемую fallback-страницу; неизвестные имена тоже направляются на неё.

Для квоты выбирается приём, отдача или оба направления. Считаются байты TLS-потока, включая TLS-заголовки и рукопожатие, без TCP/IP-заголовков и повторных передач. Счётчики сохраняются каждую секунду; при аварийном завершении последняя секунда может быть потеряна. После достижения лимита новые HTTP-запросы получают 429, а активные соединения закрываются. Пауза сервера даёт 503. День начинается в 00:00 часового пояса `PANEL_TIMEZONE`. Месячный период начинается в число создания сервера; если такого числа в месяце нет, используется последний день.

Папка `/var/lib/fluxgate` или Docker-том содержит SQLite, сертификаты и конфигурацию HAProxy. Для резервной копии сохраняйте данные и файл секретов вместе. Токен Telegram шифруется ключом `PANEL_MASTER_KEY`; смена ключа делает сохранённый токен недоступным и завершает текущие сеансы панели.

## Проверки разработчика

Из корня проекта: `go test ./...` и `go vet ./...`. В `web/`: `npm ci && npm run build`. При наличии HAProxy приложение проверяет каждую новую конфигурацию командой `haproxy -c`; контейнер HAProxy повторно проверяет её перед перезагрузкой.
